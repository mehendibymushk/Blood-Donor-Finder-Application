🩸 Blood Donor Finder Application

About the Project

Blood Donor Finder Application is a web-based platform developed to connect blood donors with people who need blood. It helps users find available donors based on blood group and location.

✨ Features

- Donor Registration and Login
- Donor Profile Management
- Search Donors by Blood Group and City
- Donor Availability Status
- GPS Location Sharing
- Nearby Donor Search
- Blood Request Management
- Email Notifications
- Admin Dashboard
- Donor Management

💻 Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP
- PHPMailer

⚙️ Installation

1. Download or clone this repository.
2. Place the project folder inside XAMPP's "htdocs" directory.
3. Start Apache and MySQL.
4. Create the required database using phpMyAdmin.
5. Configure your local database settings using "db.example.php" as a reference.
6. Configure email settings using "mail-config.example.php" if required.
7. Install dependencies using "composer install".
8. Open your browser and visit "http://localhost/BDFA/".

🎯 Project Objective

The main objective of this project is to make finding blood donors easier and faster through a simple web-based platform.
